## What Is ResponseLink OS™?

ResponseLink OS™ is a digital coordination platform built to help community organisations manage welfare visits, outreach tasks, service user check-ins, responder updates, incident reports, escalation workflows, and evidence records.

It connects three interfaces:

| Interface | Who Uses It | What It Does |
|-----------|-------------|--------------|
| **Command Dashboard** | Supervisors, coordinators, admins | Mission control — all active missions, responder status, service user alerts, AI advisory flags, reports |
| **Responder PWA** | Field workers, outreach staff | Mobile workflow — accept missions, update status, submit welfare checklists, log incidents, evidence |
| **Service User PWA** | People receiving support | Personal portal — wellbeing check-ins, help signals, visit confirmations, support updates |

All three interfaces share a single SSOT (single source of truth) data layer.

## How To Open The Demo

### Live URL
**https://responselinkosv1.vercel.app**

### Step 1 — Homepage
The homepage explains the product and has direct shortcut buttons for all three interfaces.

### Step 2 — Command Dashboard → `/#/dashboard`
Opens in Demo Mode. Shows active missions, responder status, service user check-ins, risk flags, AI advisory overview, sync status, and sidebar navigation to all modules.

### Step 3 — Responder PWA → `/#/responder-app`
Field responder mobile workflow. Mission list → travelling → arrived → in progress → welfare checklist → completed. Best viewed on a mobile device or narrow browser window.

### Step 4 — Service User PWA → `/#/service-user-pwa`
Wellbeing check-in, help signals, visit confirmation, support needs. Simple and accessible.
